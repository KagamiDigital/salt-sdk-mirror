    Type Alias SignMessageStage

    SignMessageStage: "signing" | "success" | "failure"

    The stage a host message-signing ceremony is in, reported by the stateChanged event. Message signing has no on-chain broadcast or database record, so its lifecycle is shorter than a transaction's TransactionStage: it runs the MPC signing rounds, then ends in success or failure.

    Type Declaration

    • "signing"

      Running the MPC signing rounds — co-signers nudged, huddle assembling.

    • "success"

      The signature was assembled and the signer address recovered.

    • "failure"

      The ceremony failed (see the rejected promise for the cause).
