    Interface SaltCeremony

    Common interface implemented by every MPC ceremony. Drive any ceremony — keygen or signing, host or joiner — with a single await ceremony.wait().

    Example: Uniform handling regardless of ceremony type

    listener.on('nudgeReceived', async ({ join }) => {
      const ceremony = await join();
      await ceremony.wait();
    });
    interface SaltCeremony {
        wait(): Promise<unknown>;
    }
